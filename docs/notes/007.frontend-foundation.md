# 2. React Project Structure

We decided **not to create empty folders upfront**.

Feature-specific folders will be created when the corresponding feature is implemented.

The intended structure can evolve toward:

```text
src/
├── components/
├── layouts/
├── pages/
├── routes/
├── services/
├── hooks/
├── lib/
├── assets/
├── App.tsx
├── App.css
├── index.css
└── main.tsx
```

### Folder Responsibilities

| Folder        | Purpose                          |
| ------------- | -------------------------------- |
| `components/` | Reusable UI components           |
| `layouts/`    | Application/page layouts         |
| `pages/`      | Route-level screens              |
| `routes/`     | React Router configuration       |
| `services/`   | API communication                |
| `hooks/`      | Reusable React hooks             |
| `lib/`        | Shared utilities/configuration   |
| `assets/`     | Images and other frontend assets |

# 3. React Router

## Installation

Install React Router:

```bash
npm install react-router
```

## BrowserRouter

Wrap the application with `BrowserRouter` in `main.tsx`:

```tsx
import React from "react";
import ReactDOM from "react-dom/client";
import { BrowserRouter } from "react-router";
import App from "./App.tsx";
import "./index.css";

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </React.StrictMode>,
);
```

## Routes

Routes are defined using `Routes` and `Route`.

Example:

```tsx
import { Link, Route, Routes } from "react-router";

function Home() {
  return (
    <main>
      <h1>YumYard</h1>
      <Link to="/test">Go to test</Link>
    </main>
  );
}

function Test() {
  return (
    <main>
      <h1>Test Page</h1>
      <Link to="/">Back home</Link>
    </main>
  );
}

function App() {
  return (
    <Routes>
      <Route path="/" element={<Home />} />
      <Route path="/test" element={<Test />} />
    </Routes>
  );
}

export default App;
```

# 4. Tailwind CSS v4.3

YumYard uses Tailwind CSS with the Vite integration.

## Installation

From the frontend directory:

```bash
npm install tailwindcss @tailwindcss/vite
```

## Vite Configuration

Add the Tailwind Vite plugin to `vite.config.ts`:

```ts
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
  plugins: [react(), tailwindcss()],
});
```

## Global CSS

Replace the contents of `src/index.css` with:

```css
@import "tailwindcss";
```

Tailwind v4 uses this import instead of the older:

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

## Verification

Temporarily test Tailwind in `App.tsx`:

```tsx
function App() {
  return (
    <main className="flex min-h-screen items-center justify-center">
      <h1 className="text-4xl font-bold">YumYard</h1>
    </main>
  );
}

export default App;
```

Run:

```bash
npm run dev
```

If the text appears large, bold, and centered, Tailwind is working.
